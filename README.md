# Tocador

Página pessoal que roda um jogo de RPG Maker XP guardado no próprio aparelho. Nenhum jogo é distribuído aqui.

Motor: mkxp-z (libretro, compilado para WebAssembly), GPL-2.0, código-fonte em https://github.com/white-axe/mkxp-z/tree/libretro (PR https://github.com/mkxp-z/mkxp-z/pull/255). Interface: Nostalgist.js (MIT) e RetroArch (GPL-3.0), conforme a página de exemplo https://white-axe.github.io/mkxp-z-libretro-emscripten/.
